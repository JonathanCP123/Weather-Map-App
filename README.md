# 🌦️ Weather & Route Map App

An interactive web application built with **React**, **TypeScript**, and **Vite** that combines Google Maps functionality with real-time location details, weather insights, and route planning.

---

## 🚀 Live Demo

Check out the live application hosted on GitHub Pages:  
👉 **[https://jonathancp123.github.io/Weather-Map-App/](https://jonathancp123.github.io/Weather-Map-App/)**

---

## ✨ Features

* **🗺️ Interactive Map & Location Search**: Search for places around New Zealand with the displayed map and information cards.
* **🚗 Route & Directions Planning**: Calculate travel routes between locations and display routes directly on the map.
* **🌦️ Integrated Weather Updates**: View location-based weather information while exploring places and planning trips.
* **⚡ Fast & Modern Build**: Powered by Vite for instant Hot Module Replacement (HMR) and fast build times.
* **📘 Fully Typed**: Written with TypeScript for clean, predictable, and maintainable code.
* **📱 Mobile-First Responsive UI:** Floating control panel on desktop that automatically transitions to a touch-optimized bottom drawer on mobile devices.

---

## 🛠️ Tech Stack

* **Frontend**: React, TypeScript, HTML5, CSS3
* **Bundler & Tooling**: Vite
* **APIs**: Google Maps JavaScript API (Places, Directions, Maps)
* **Deployment**: GitHub Pages (`gh-pages`)
